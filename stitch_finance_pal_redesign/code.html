Arquitectura Criptográfica

Cifrado y Privacidad de Grado Militar

Tus datos nunca se venden ni se procesan en la nube para generar perfiles crediticios. Soberanía total garantizada por código.

AES-GCM 256 + PBKDF2

Derivación de claves locales mediante 100,000 iteraciones PBKDF2. Los datos sensibles se encriptan antes de tocar el almacenamiento.

✓ Llave derivada en el cliente

100% Local-First (SQLite)

La base de datos SQLite y memoria segura residen en tu terminal. La app arranca al instante sin requerir internet de por vida.

✓ Cero latencia de red

Sync Opcional Supabase (RLS)

Si decides activar la nube, cada fila queda aislada por tu UID con Row Level Security y cola offline Zustand con reintentos.

✓ 100% Gratuito y Opcional
